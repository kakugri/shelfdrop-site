Support

ShelfDrop is an iOS audiobook app for importing DRM-free audiobook files from Files or from a computer on the same local network.

Contact

Email akugri95@gmail.com and include:

  • Your iPhone or iPad model.
  • iOS version.
  • ShelfDrop app version and build number.
  • Install source: App Store or TestFlight.
  • Whether the issue happened with Files import, Receive mode, Library, Player, Settings, or deletion.
  • File type, such as .m4b, .mp3, .m4a, folder upload, or .zip.
  • Browser and operating system if using Receive mode from a computer.
  • What you expected to happen and what happened instead.

Do not attach copyrighted audiobook files to support reports.

Common Checks

Receive Mode

  • Keep ShelfDrop open on the Receive tab during upload.
  • Make sure the computer and iPhone are on the same Wi-Fi network.
  • Avoid guest Wi-Fi networks that block local devices from seeing each other.
  • Use Chrome or Edge for folder uploads from Windows.
  • If the browser shows an error, stop Receive mode, start it again, and use the new code or QR code.
  • If iOS asks for local network permission, allow it for ShelfDrop.

Import And Playback

  • Confirm the file is DRM-free.
  • Confirm the file is fully downloaded locally if it comes from iCloud Drive or another Files provider.
  • Try deleting and re-importing the book if import was interrupted.
  • Check available device storage before importing large audiobooks.

Storage

  • ShelfDrop stores imported books in the app's local storage.
  • Delete books from ShelfDrop's Library to remove imported copies.
  • Deleting the app removes imported books and local playback progress.
